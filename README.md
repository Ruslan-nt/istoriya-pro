# История PRO — PWA

Готовый стартовый проект устанавливаемого веб-приложения для подготовки по истории в 10–11 классах.

## Что внутри
- Адаптивный интерфейс в синей цветовой гамме.
- Переключение 10/11 класса.
- Учебные темы по истории России и всемирной истории.
- Тестовый тренажёр с ответами и пояснениями.
- Хронология с поиском.
- Баллы, достижения и локальное сохранение прогресса.
- PWA-манифест, иконки и service worker для офлайн-кэша.

## Важно
Это рабочая стартовая версия, а не готовый официальный банк ЕГЭ. Вопросы демонстрационные; перед учебным/коммерческим запуском расширьте и проверьте контент, добавьте задания по картам и источникам, полноценную экзаменационную модель и серверную учётную запись. Прогресс сейчас хранится только в браузере конкретного устройства и не синхронизируется между друзьями.

## Локальный запуск
PWA и service worker требуют HTTPS или localhost. В папке проекта выполните:

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.

## Бесплатная публикация на GitHub Pages
1. Создайте аккаунт на GitHub и новый публичный репозиторий, например `istoriya-pro`.
2. Распакуйте ZIP и загрузите в репозиторий все файлы и папку `icons` (именно содержимое проекта, а не ZIP).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
6. Дождитесь публикации. Адрес будет вида `https://ВАШ-ЛОГИН.github.io/istoriya-pro/`.
7. Откройте опубликованный HTTPS-адрес на телефоне.

## Установка на телефон
### Android
Откройте сайт в Chrome. Нажмите **Установить приложение** или меню ⋮ → **Установить приложение / Добавить на главный экран**.

### iPhone
Откройте сайт в Safari → **Поделиться** → **На экран Домой** → включите **Открывать как веб-приложение**, если такой переключатель доступен → **Добавить**.

## Как поделиться с друзьями
Отправьте друзьям опубликованную HTTPS-ссылку. Каждый сможет установить приложение на свой телефон. В текущей версии прогресс у каждого пользователя отдельный, так как он хранится локально.

## Обновление
После изменения файлов увеличьте значение `CACHE` в `sw.js` (например, `history-pro-v2`), затем загрузите изменения на хостинг. Это заставит браузер получить новый кэш.
